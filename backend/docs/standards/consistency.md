# 一致性实现标准

一致性敏感变更开始前必须更新模块的 `FACTS.md`、`INVARIANTS.md`、`STATE-MACHINE.md` 和 `TRANSACTIONS.md`。

- 状态转换采用条件更新或乐观版本，拒绝非法旧状态。
- 命令、回调和消费者以稳定业务键幂等，不能用模糊“似乎处理过”判断。
- 数据库提交与消息发布使用 Outbox；消费者使用 Inbox/event ID 去重并校验聚合版本。
- 外部调用超时进入结果未知状态，通过查询、回调或对账收敛。
- 重试有上限、退避、抖动，只覆盖明确瞬时错误，并响应 context cancellation。
- 补偿自身幂等，校验当前状态，不能覆盖后续合法状态。
