# Platform 命名规范检查

本模块对外名字空间的检查入口。权威是本仓库 [`开发规范.md`](./开发规范.md) 第 6 章，不是模块外文档。Platform 的 id **必须含 surface**。

| 用途 | 文档 |
|---|---|
| 人工 / Agent 评审 | [命名规范检查提示词.md](./命名规范检查提示词.md) |

改 `protocol/manifest/platform` 碎片或 `g.Meta` 之后：先 `manifestcompose`，再按检查提示词跑本模块。工具落地后执行：

```powershell
./business/backend/tools/verify-naming.ps1
```

碎片变更必须 compose 进 `business/module.json`，并 `manifestcompose -mode check`。`verify-fast.ps1` 必须在工具落地后调用命名检查。未落地前不要做空壳脚本冒充通过。

## 范围

| 项 | 值 |
|---|---|
| module | `platform` |
| Manifest | `business/module.json`（由 `protocol/manifest/platform` compose） |
| HTTP prefix | `/admin/platform/<domain>` |
| id | `platform.admin.<domain>.<feature?>.<method>` |
| g.Meta | `business/backend/internal/application/**/api/**/*.go` |
| 前端 | `business/frontend-admin/src` |

登记 domain：`registry` `settings` `audit` `live-providers` `sms` `email` `storage` `notify-events` `notify-templates` `notify-channels` `edge`。

公开对象读取若脱离 surface（例如 `/uploads/...`），id 仍写完整 `platform.admin.storage.objects.get`。内部 `/internal/v1` 不与对外 Manifest 混比。命令词 `default` 用于唯一默认通道。
