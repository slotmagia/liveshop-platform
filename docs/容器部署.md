# Platform 容器部署

Platform 拥有 Registry、站点配置、控制面 Admin artifact，以及本地 gRPC 证书卷 `liveshop-grpc-certs`。Gateway 与四端 Host **不在**本仓库 Compose 中。

## 完整环境

工作区根目录按依赖顺序启动全部模块、注册不可变 release、导入本地授权并做冒烟：

```powershell
pwsh -File .\deploy-local-containers.ps1
```

默认保留所有模块的 MySQL 命名卷。前端 artifact 重建时会自动注册下一个补丁版本，不必清库。

停止（保留数据库卷）：

```powershell
pwsh -File .\stop-local-containers.ps1
```

只有需要空库时才使用 `-Fresh`（会删除全部数据库卷）：

```powershell
pwsh -File .\deploy-local-containers.ps1 -Fresh
```

只重建 Registry、保留业务数据：

```powershell
pwsh -File .\deploy-local-containers.ps1 -ResetRegistry
```

## 本模块脚本

在 `liveshop-platform` 仓库根：

```powershell
pwsh -File .\business\backend\tools\up-local.ps1
pwsh -File .\business\backend\tools\up-local.ps1 -Register
pwsh -File .\business\backend\tools\up-local.ps1 -Fresh -Register
pwsh -File .\business\backend\tools\down-local.ps1
pwsh -File .\business\backend\tools\down-local.ps1 -Volumes
```

| 脚本 | 作用 |
|---|---|
| `tools/up-local.ps1` | 创建 `liveshop-local` 网络、引导 gRPC 证书、启动 Registry MySQL / 迁移 / Platform / 控制面 artifact |
| `tools/up-local.ps1 -Register` | 启动后把本仓库 `module.json` 注册并激活到 Registry |
| `tools/down-local.ps1` | 停止本 Compose 项目，默认保留卷 |
| `tools/register-platform-module.ps1` | 仅注册/激活，不重建容器 |

`-Volumes` 会删除 `liveshop-grpc-certs`。若 Identity 仍在运行，先停 Identity。

进程内开发（非容器）仍用 `tools/launch-local.ps1`，与本文容器路径分开。

## 依赖顺序

```text
本模块 → Identity → Gateway/Hosts → Catalog → Trade → Live
```

本模块必须先于 Identity：Identity 启动时拉取活动 Registry，失败则关闭就绪。

## 端口与服务

| 服务 | 地址 |
|---|---|
| Platform HTTP | `http://127.0.0.1:18082` |
| Platform gRPC | `127.0.0.1:19082` / 容器内 `platform:19082` |
| 控制面 Admin artifact | `http://127.0.0.1:15180` |
| Registry MySQL | `127.0.0.1:33069`；migrate 之后 `tools/seed-local.sql` 写入本地 OTP 通知模板 |

容器网络名：`liveshop-local`。证书卷名：`liveshop-grpc-certs`（Platform 生产，Identity 只读挂载）。

## Compose 与镜像

- Compose：`business/backend/deploy/compose.local.yml`
- 后端镜像：`business/backend/deploy/Dockerfile`
- 控制面前端：`business/backend/deploy/frontend.Dockerfile`（本仓库 workspace 构建 `@liveshops/host-sdk` 与 `@liveshops/design-tokens`；其他微服务不得 COPY 本仓库源码，应 `npm install` 已发布版本）

## 常见失败

- `release_immutable`：同版本 artifact digest 变了。全栈脚本会自动注册下一个补丁版本并保留业务库；不必 `-Fresh`。若 Registry 损坏再用 `-ResetRegistry`。
- Identity 报证书为空：先完成本模块 `up-local.ps1`，再启动 Identity。
