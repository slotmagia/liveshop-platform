# Platform 外部契约

## 浏览器

Platform Admin contribution 通过 Gateway 调用 Manifest 声明的 HTTP route，并携带 Identity 签发的 Module Capability。Platform 校验 `typ=LIVESHOP-MODULE-CAPABILITY`、Identity issuer、公钥、audience、TTL、module/release/contribution/surface、registry/entitlement/authorization/identity/context revision、permission 与 allowed route，任一不匹配即拒绝。

Platform 不提供浏览器 runtime、有效授权查询或 capability 签发接口。

## 工作负载 gRPC

`liveshop.platform.v1.PlatformRegistryService` 使用 TLS 1.3 双向认证、SPIFFE workload identity 与逐方法权限：

| 方法 | 调用方 | 权限 | 结果 |
|---|---|---|---|
| `GetRouteSnapshot` | Gateway | `platform.registry.routes.read` | revision + 活动 HTTP 路由 |
| `GetActiveCapabilitySnapshot` | Identity | `platform.registry.active-capabilities.read` | revision + 完整结构化活动能力目录 |

活动能力目录包含 module/release/digest/backend、permission definitions、contributions、artifact、frontend contract、navigation、allowed routes、HTTP operations 与 gRPC contract。它不包含用户授权结果；Identity 使用自身事实过滤后才对浏览器暴露 runtime。

## 发布

Release CI 使用独立 workload identity 注册/激活不可变 Manifest。浏览器角色权限不能替代工作负载权限。

## Admin Live Provider HTTP

| Operation | 方法与路径 | 权限 | 幂等/并发 |
|---|---|---|---|
| `platform.admin.live-providers.drivers.list` | `GET /admin/platform/live-providers/drivers` | `platform.live-provider.read` | safe；返回驱动拥有的表单元数据，不含凭据值 |
| `platform.admin.live-providers.list` | `GET /admin/platform/live-providers` | `platform.live-provider.read` | safe；只返回脱敏凭据状态 |
| `platform.admin.live-providers.update` | `PUT /admin/platform/live-providers/{code}` | `platform.live-provider.manage` | `commandKey + expectedVersion` |
| `platform.admin.live-providers.retire` | `POST /admin/platform/live-providers/{code}/retire` | `platform.live-provider.manage` | `commandKey + expectedVersion` |

浏览器不能提交商户/店铺范围；Admin Module Capability 不携带店铺上下文，claims 也不再包含 `appId`/`commercialId`，因此本接口写入单全局 Provider 目录。Admin 必须按驱动元数据生成字段，不能自行维护另一份驱动条件表单。所有驱动表单必须显式提交 `enabled`，创建默认值为 `true`；缺少该参数的写请求直接拒绝，不能按 Go 布尔零值解释为停用。密钥变更显式使用 `KEEP / REPLACE / CLEAR`；读取不返回明文。物理 DELETE 不公开。

## 授权数据迁移

Platform export、Identity IAM receipt 与 Subscription entitlement receipt 契约见 [`授权交接.md`](../授权交接.md)。这是一次性交接，不是运行时 API，也不存在双读、双写或 fallback。
