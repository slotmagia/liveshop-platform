# 边缘动态路由与证书事务

Ask / Route / Snapshot 是只读路径。它们读取 Platform `domain-base` 文档，并同步调用 Identity 内部解析；任一侧失败则 fail closed（Ask 500，Route 500，Snapshot 不可用）。

`domain-base` 写入仍是 Settings 的版本化事务：校验 catalog、比较 expectedVersion、提交文档。Caddy 热加载发生在该事务提交之后：

1. 提交 `platform_setting`。
2. 若 `edge.enabled`，渲染 Caddyfile、写入配置文件、POST Caddy admin `/load`。
3. 步骤 2 失败不回滚步骤 1。调用方看到依赖不可用，使用新的 expectedVersion 重试保存。

Identity 自定义域名写入仍在 Identity 事务内完成。Platform 不订阅 outbox、不双写绑定行。
