# 边缘动态路由与证书状态机

证书材料由 Caddy 持有。Platform 只决定「这个主机现在能不能签 / 该打到哪」。

## 证书准入

```text
未知或非法主机 ──ask──> 拒签（400 / 404）
平台入口主机 ──ask──> 允许
保留根域 / CNAME 目标（非入口）──ask──> 拒签
自定义 PENDING / FAILED / 叠加层非 active / 店铺已关闭 ──ask──> 拒签
自定义 VERIFIED ∧ 叠加层 active ∧ 店铺未关闭 ──ask──> 允许
{slug}.{root} 且店铺未关闭 ──ask──> 允许
```

Identity 侧自定义域名状态机见 Identity `shop-domain`。本切片不增加 `provisioning_cert` 行状态。

## Caddyfile 应用

```text
edge.enabled=false ──Apply──> 空操作
edge.enabled=true ∧ 主域名不完整 ──Apply──> 失败（设置已提交）
edge.enabled=true ∧ 主域名完整 ──Render──> POST Caddy /load
Caddy /load 失败 ──> UNKNOWN（重试保存，不回滚 platform_setting）
```

## 路由

```text
平台入口主机 ──route──> 对应上游
自定义 VERIFIED SHOP ──route──> 商城上游
自定义 VERIFIED LIVE ──route──> 直播上游
{slug}.{root} ──route──> 商城上游
未绑定 ──route──> 403
```
