# 边缘动态路由与证书对外契约

浏览器不得调用下列接口。Caddy 与 Gateway 走 Platform 进程 HTTP，不经过模块 Manifest 路由快照。

## Caddy ask / Gateway route（classic HTTP）

鉴权：`X-Liveshop-Internal-Grant` 或 query `grant`，值等于部署 `internal_grant.token`。Caddy ask 不能方便地带自定义头，因此允许 query。

| 方法与路径 | 查询 | 成功 | 拒绝 |
|---|---|---|---|
| `GET /internal/platform/edge/hosts/allowed` | `domain` 或 `host` | 200 空体，允许 ACME | 400 非法；404 未绑定；403 自定义未验证；401 无 grant |
| `GET /internal/platform/edge/hosts/route` | `host` 或 `domain` | 200，`X-Upstream`，`X-Liveshop-Edge-Kind`，`X-Liveshop-Edge-Target` | 400 非法；403 未绑定；401 无 grant |

`X-Upstream` 是配置的上游地址（如 `shop-host:18080`）。Kind 为 `platform` / `custom` / `slug`。Target 为 `shop` / `live` / `merch` / `admin` / `rts`。

旧路径 `/internal/domain-allowed`、`/internal/host-route` 不再提供。

## Identity 读取快照（JSON 信封）

| 方法与路径 | 调用方 | 结果 |
|---|---|---|
| `GET /internal/v1/edge/snapshot` | Identity（内部 grant） | CNAME 目标、六个入口主机、`forceHttps`、保留主机列表 |

Identity merch 域名页的 CNAME 指令必须读本快照，不得使用进程内静态配置冒充 Platform 事实。

## Identity 主机解析（JSON 信封）

Platform 调用 Identity `GET /internal/v1/domains/resolve?host=&rootDomain=`（内部 grant）。响应含 `kind=custom|slug`、店铺范围、域名状态、叠加层。未命中 404。这不是 Directory IAM。

## 本切片不做

- Shop/Live Host 按 Host 头解析租户（仍可用编译期 shopCode）。
- `{roomCode}.{root}` 房间站点。
- `pull.{root}` SRS 拉流。
- Gateway `auth_request` 装配（消费本契约的后续切片）。
