# 边缘动态路由与证书不变量

1. 平台入口主机（商城 / 直播 / 商户后台 / 总后台 / 推流端）始终允许签发证书，并路由到配置的对应上游。
2. `root_domain` 与 `custom_domain_cname_target` 是保留主机：不是店铺站点，商户不得把它们绑成自定义域名。
3. 六个入口主机（含根域）必须合法 FQDN 且互不相同，才允许生成 Caddyfile。
4. 自定义主机只有 Identity 状态 `VERIFIED`、叠加层 `active`（缺行视为 active）、店铺未关闭时才允许 ACME；`PENDING` / `FAILED` / 受限 / 停用叠加层一律拒签。
5. 自定义主机路由：`SHOP` → 商城上游，`LIVE` → 直播上游。平台 `{slug}.{root_domain}` 只解析店铺 `code` 然后 `subdomain`，路由到商城上游；房间级子域名不在本切片。
6. 证书私钥不得写入 Platform 或 Identity。Caddy 失败不得回滚已提交的 `domain-base` 版本。
7. Ask / Route 是 classic HTTP，不走 `{code,data}` 信封。未绑定 Ask 返回 404，未绑定 Route 返回 403。
8. 浏览器不得调用 Ask / Route / Snapshot。内部 grant 与 Identity 查询使用同一部署令牌，不得用 Directory IAM RPC。
9. `edge.enabled=false` 时仍可解析主机（供测试与 Gateway）；只是不生成或热加载 Caddyfile。
