# Registry 状态机

## Release

```text
ABSENT --Register(valid manifest,digest)--> REGISTERED
REGISTERED --Activate(all invariants pass)--> ACTIVE
ACTIVE(v1) --Activate(v2, all invariants pass)--> REGISTERED(v1) + ACTIVE(v2)
ACTIVE(v1) --Activate(v1)--> ACTIVE(v1)  [幂等，无副作用]
```

非法转换：未注册版本激活、Manifest/digest 冲突注册、活动权限定义冲突、同 `(surface, groupId)` 导航标题或排序冲突。非法转换必须在事务内失败，状态与 revision 不变。

## 旧授权交接

```text
LEGACY_PRESENT
  --Export--> EXPORTED(digest,rowCount)
  --Identity durable IAM import--> IAM_IMPORTED(identityReceipt,digest,rowCount)
  --Subscription durable entitlement import--> BOTH_IMPORTED(identityReceipt,subscriptionReceipt,digest,rowCount)
  --Finalize(both valid receipts)--> RETIRED
```

重复 Export 返回相同 ledger payload；重复 Finalize 在合法终态收敛。不能从 `EXPORTED` 或单回执状态直接到 `RETIRED`，本地 export ledger 不能替代两份目标 receipt。

## Live Provider

```text
ABSENT --Put(expectedVersion=0)--> ACTIVE(version=1)
ACTIVE(vN) --Put(expectedVersion=vN)--> ACTIVE(vN+1)
ACTIVE(vN) --Retire(expectedVersion=vN)--> RETIRED(vN+1)
RETIRED --Put/Retire(new command)--> CONFLICT
```

设置新默认项时，其他默认项在同一事务执行 `ACTIVE(vN, default=true) -> ACTIVE(vN+1, default=false)`。旧版本、错误版本、复用不同请求的 commandKey、停用但设为默认、无效驱动/编码组合均为非法转换，不能留下部分快照、Audit 或命令回执。
