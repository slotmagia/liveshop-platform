# Liveshop Platform 架构

`liveshop-platform` 是模块控制面和跨业务基础设施控制面，拥有 Registry、Navigation、Settings、Audit、Notification、Storage、Telemetry/Attribution、Live Provider 与 Localization。浏览器用户、组织、成员、角色、策略、授予、数据范围、权益投影、登录会话、游客风险、客服账号、商户治理与 Module Capability 签发全部由 `liveshop-identity` 拥有。

## 运行边界

```text
Release CI --workload bearer--> Platform Registry 写接口
Gateway    --workload bearer--> Platform Registry 路由快照
Gateway    --mTLS/SPIFFE------> Platform GetRouteSnapshot
Identity   --mTLS/SPIFFE------> Platform GetActiveCapabilitySnapshot
Browser    --Identity Module Capability--> Gateway --> Platform Admin API
Modules    --mTLS + idempotency key------> Platform Notification/Storage/Telemetry
Live       --mTLS + version--------------> Platform Live Provider snapshot
```

- Platform 只配置 Identity 的 Module Capability issuer、公钥和 key ID，绝不保存签发私钥。
- Admin API 再次校验 capability 的 module、release、contribution、surface、method/path、权限及 revision claims；浏览器字段不能扩大签名上下文。
- gRPC 入口要求 TLS 1.3 双向认证。Gateway SPIFFE 只能调用 `GetRouteSnapshot`；Identity SPIFFE 只能调用 `GetActiveCapabilitySnapshot`。
- 浏览器不存在直达 Platform 的认证、IAM 或 Runtime API。

## Registry 一致性

`platform_registry_state` 是模块发布、活动版本和单调 revision 的唯一事实源。激活事务在一个 MySQL 事务内完成：

1. 锁定 Registry 聚合。
2. 校验发布存在、路由不冲突、同一 `(surface, groupId)` 的导航标题和排序完全一致。
3. 更新活动版本、revision 和活动权限目录。
4. 写入控制面审计。

任一步失败都会回滚。活动能力快照与路由快照从同一次 Registry 状态读取派生，并携带相同 revision。活动能力快照只包含当前活动不可变发布，包含权限定义、贡献、导航、artifact、前端 props/events/actions、allowed routes、HTTP 字段与响应、gRPC 合约和后端位置。

## 数据库

Platform 目标表族包括：

- `platform_registry_state`
- `platform_permission_catalog`（活动 Manifest 权限定义，不是用户 grant）
- `platform_setting`
- `platform_audit_event`
- `notification_*`
- `storage_*`
- `telemetry_*`、`attribution_*`
- `live_provider_*`
- `localization_*`
- 一次性授权迁移 export/receipt ledger

历史 IAM/Authorization 表不会被新部署创建。升级数据库中的历史表只作为 `authorizationexport` 输入；Identity 签名确认持久导入前绝不删除。详见 [授权交接.md](./授权交接.md)。

## 目录

```text
backend/internal/
├── application/admin/       # Registry、Settings、Audit、Provider 与 Telemetry 页面 API
├── controlplane/provisioning/ # Release、Gateway、Identity 工作负载接口
├── biz/                     # 控制面用例、Registry 聚合与 capability/*
├── data/                    # MySQL / memory adapters
├── common/                  # Module Capability 与 workload 验证
└── app/                     # 组合根和进程生命周期
```

Platform 只发布 `frontend-admin`；不存在 `application/merch` 或 `frontend-merch`。
